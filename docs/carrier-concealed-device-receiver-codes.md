# Carrier Concealed Device Receiver Fault Codes

Source: user-provided image `1000206559.png`.

Target device: Carrier Classicool concealed cooling/heating inverter models.

| Code | Arabic fault description |
|---|---|
| E0 | عطل الوحدة الإلكترونية (عطل EEPROM) |
| E1 | خطأ في الاتصال بين الوحدتين الداخلية والخارجية أو سقوط فازة L1 |
| E3 | عطل في التحكم في موتور مروحة الوحدة الداخلية |
| E4 | حساس الهواء الراجع إلى الوحدة الداخلية: فتح كهربائي أو قصر كهربائي |
| E5 | حساس المبادِل الحراري الأول للوحدة الداخلية: فتح كهربائي أو قصر كهربائي |
| EC | وجود تنفيس في دائرة الفريون أو عطل أدى إلى إيقاف تشغيل الضاغط |
| EE | حساس طلبة تصريف مياه التكييف عند استخدام طلبة التصريف الاختيارية |
| FA | الحماية من ارتفاع التيار لبعض الماكينات |
| F1 | حساس الهواء الراجع للوحدة الخارجية: فتح كهربائي أو قصر كهربائي |
| F2 | حساس المبادِل الحراري للوحدة الخارجية: فتح كهربائي أو قصر كهربائي |
| F3 | حساس ارتفاع درجة حرارة الضاغط: فتح كهربائي أو قصر كهربائي |
| F4 | عطل بالوحدة الإلكترونية الموجودة بالوحدة الخارجية (عطل EEPROM) |
| F5 | موتور مروحة الوحدة الخارجية لا يعمل |
| P0 | عطل بالوحدة الإلكترونية IPM وعمل وظيفة الحماية |
| P1 | حماية من ارتفاع أو انخفاض الجهد الكهربائي المستمر |
| P2 | عطل أدى إلى عمل وظيفة حماية من ارتفاع درجة حرارة الضاغط أو توقف تشغيل الضاغط |
| P3 | عطل أدى إلى عمل وظيفة حماية من انخفاض درجة الحرارة المحيطة |
| P4 | عطل أدى إلى إيقاف تشغيل الضاغط الإنفرتر |
| P6 | عطل أدى إلى عمل وظيفة حماية من انخفاض أو ارتفاع ضغط الوحدة الخارجية |
| P7 | عطل بالوحدة الإلكترونية IGBT وعمل وظيفة الحماية بالوحدة الخارجية |
| F8 | خطأ في الاتصال بين شريحتي الوحدة الداخلية |
